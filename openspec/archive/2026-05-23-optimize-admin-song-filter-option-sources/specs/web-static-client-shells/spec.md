## ADDED Requirements

### Requirement: 后台歌曲管理页快速筛选选项来源

后台壳内歌曲管理页「更多筛选」中，原唱、作词、作曲、标签、语言五个维度的下拉可选项 MUST 取自参考数据管理列表，而非从当前曲库歌曲字段推导；格式维度不受本要求约束。

各维度选项来源 SHALL 为：

| 维度 | 数据来源 | 过滤规则 |
|------|----------|----------|
| 原唱 | 艺人管理（`/people`） | `types` 包含「歌手」 |
| 作词 | 艺人管理 | `types` 包含「作词」 |
| 作曲 | 艺人管理 | `types` 包含「作曲」 |
| 标签 | 标签管理（`/tags`） | 全部标签名称 |
| 语言 | 语言管理（`/languages`） | 全部语言名称 |

选项值 SHALL 为对应条目的 **名称** 字符串（与列表过滤时使用的歌曲元数据字段一致），并按名称升序排列。

#### Scenario: 原唱选项来自歌手类型艺人

- **GIVEN** 艺人管理中存在名称「甲」且 `types` 包含「歌手」，存在名称「乙」且 `types` 仅包含「作词」
- **WHEN** 用户打开歌曲管理页「更多筛选」中的原唱下拉
- **THEN** 可选项包含「甲」
- **AND** 可选项不包含「乙」

#### Scenario: 作词与作曲选项按类型区分

- **GIVEN** 艺人「丙」的 `types` 为「作词」，艺人「丁」的 `types` 为「作曲」
- **WHEN** 用户分别打开作词、作曲筛选下拉
- **THEN** 作词可选项包含「丙」且不包含「丁」（除非「丁」亦为作词类型）
- **AND** 作曲可选项包含「丁」且不包含「丙」（除非「丙」亦为作曲类型）

#### Scenario: 标签与语言选项来自管理列表

- **GIVEN** 标签管理中存在「流行」，语言管理中存在「国语」，且当前曲库中没有任何歌曲带有该标签或语言
- **WHEN** 用户打开标签或语言筛选下拉
- **THEN** 可选项仍包含「流行」或「国语」

#### Scenario: 参考数据变更后刷新筛选项

- **GIVEN** 用户已在歌曲管理页
- **WHEN** 客户端完成艺人、标签或语言管理数据的重新加载（如新增、编辑、删除后触发的 `loadPeople` / `loadTags` / `loadLanguages`）
- **THEN** 对应维度的下拉选项列表更新为与管理数据一致的集合
- **AND** 仍保留当前仍存在于新选项列表中的已选值

## MODIFIED Requirements

### Requirement: 后台歌曲管理页快速筛选可搜索多选

后台壳内歌曲管理页的「更多筛选」面板 SHALL 为原唱、作词、作曲、标签、格式、语言六个维度提供可搜索的多选下拉；用户 MUST 能通过关键字模糊匹配选项，并勾选或取消勾选多项；同一维度内多选为 OR，不同维度之间为 AND。原唱、作词、作曲、标签、语言五个维度的可选项来源 SHALL 符合「后台歌曲管理页快速筛选选项来源」要求。

#### Scenario: 勾选后状态保持

- **GIVEN** 用户已打开「更多筛选」并展开某一维度的下拉
- **WHEN** 用户勾选或取消勾选某一选项
- **THEN** 该选项的勾选状态立即反映在 checkbox 上
- **AND** 关闭并再次打开下拉后勾选状态与之一致
- **AND** 触发器文案反映当前选中（未选时显示维度名称，选中一项时显示该项名称，选中多项时显示合并文案或计数）

#### Scenario: 搜索过滤选项

- **GIVEN** 某维度下拉已展开且存在多个可选项
- **WHEN** 用户在搜索框输入关键字
- **THEN** 仅显示标签或值与关键字模糊匹配的选项
- **AND** 对可见选项的勾选/取消勾选仍正确更新筛选结果

#### Scenario: 筛选结果更新

- **GIVEN** 用户已在至少一个维度选中一个或多个选项
- **WHEN** 选中集合发生变化
- **THEN** 歌曲列表仅显示满足各维度 OR/AND 规则的歌曲
- **AND** 「重置」按钮可见且可清空所有快速筛选与关键词

#### Scenario: 翻页不重建筛选项

- **GIVEN** 用户已在快速筛选中选中若干选项
- **WHEN** 用户切换列表页码或修改每页条数
- **THEN** 快速筛选的选中状态与触发器文案保持不变
- **AND** 下拉选项列表不因仅表格重绘而被清空或重置

#### Scenario: 曲库或参考数据变更后刷新选项

- **GIVEN** 曲库歌曲集合发生变更（如扫描完成、重新加载歌曲列表），和/或艺人、标签、语言管理数据发生变更
- **WHEN** 客户端完成相应数据刷新
- **THEN** 各维度下拉选项列表更新为与当前数据源一致的集合（艺人/标签/语言按管理列表，格式按曲库文件格式）
- **AND** 仍保留当前仍存在于新选项列表中的已选值

#### Scenario: 单选项维度可有效勾选

- **GIVEN** 某筛选维度在当前可选项中仅有一个选项
- **WHEN** 用户勾选该唯一选项
- **THEN** 该选项保持勾选状态
- **AND** 列表按该条件过滤
- **AND** 触发器显示该选项名称而非仅显示维度名称
