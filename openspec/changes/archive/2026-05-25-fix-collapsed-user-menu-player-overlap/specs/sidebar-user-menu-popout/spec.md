## ADDED Requirements

### Requirement: 收起侧栏时用户菜单显示在底部播放器之上

当应用 shell 处于侧边栏收起状态且用户菜单已打开时，菜单（含全部菜单项）MUST 在层叠顺序上高于该壳页面底部的固定播放器/试听条，使用户可见且可点击；MUST NOT 被播放器遮挡。

#### Scenario: 前台收起侧栏菜单不被播放器遮挡

- **GIVEN** 用户已打开前台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单完整显示在底部 `.studio-player` 之上
- **AND** 用户可点击「个人资料」「退出登录」等全部菜单项

#### Scenario: 后台收起侧栏菜单不被试听条遮挡

- **GIVEN** 用户已打开后台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单完整显示在底部试听播放器（`#adminStudioPlayer`）之上
- **AND** 用户可点击「返回前台」「退出登录」等全部菜单项

#### Scenario: 展开侧栏时层叠行为不变

- **GIVEN** 用户已打开前台或后台壳页面且侧栏处于展开状态
- **WHEN** 用户打开用户菜单
- **THEN** 菜单与侧栏的 z-index / 层叠关系与本变更前一致
- **AND** 不因本变更导致展开态菜单异常盖住主内容区其它控件
