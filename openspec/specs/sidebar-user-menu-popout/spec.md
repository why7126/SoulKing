# sidebar-user-menu-popout Specification

## Purpose

定义侧边栏收起时底部用户头像下拉菜单的弹出布局：菜单须在窄轨道（64px）外侧向右浮出并保持中文菜单项横排可读；收起态菜单须在底部播放器/试听条之上完整可见可点；展开侧栏时保持既有侧栏内锚定行为；通过纯 CSS 实现，不改变菜单 HTML 与 JavaScript 开关逻辑。
## Requirements
### Requirement: 展开侧栏时用户菜单布局不变

当应用 shell 未处于侧边栏收起状态时，用户菜单的定位与宽度行为 MUST 与变更前一致（`left`/`right` 锚定在侧栏内、在头像行上方弹出）。

#### Scenario: 前台展开侧栏打开用户菜单

- **GIVEN** 用户已打开前台壳页面且侧栏处于展开状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单在侧栏底部区域内左右留白锚定显示
- **AND** 菜单项布局与视觉样式与变更前一致

#### Scenario: 后台展开侧栏打开用户菜单

- **GIVEN** 用户已打开后台壳页面且侧栏处于展开状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单在侧栏底部区域内左右留白锚定显示
- **AND** 菜单项布局与视觉样式与变更前一致

### Requirement: 收起态菜单最小可读宽度

收起侧栏时，用户菜单 MUST 具备足够的最小宽度，使最长中文菜单项（如「退出登录」「返回前台」）在单行内完整显示。

#### Scenario: 前台最长菜单项单行显示

- **GIVEN** 前台侧栏处于收起状态且用户菜单已打开
- **WHEN** 查看包含「进入后台」「退出登录」等项的菜单
- **THEN** 每项文案在单行内显示，无逐字折行

#### Scenario: 后台最长菜单项单行显示

- **GIVEN** 后台侧栏处于收起状态且用户菜单已打开
- **WHEN** 查看包含「返回前台」「退出登录」等项的菜单
- **THEN** 每项文案在单行内显示，无逐字折行

### Requirement: 纯样式实现且不改变菜单交互契约

本能力 MUST 通过 CSS 覆盖实现；MUST NOT 修改用户菜单的 HTML 结构或打开/关闭的 JavaScript 逻辑；菜单项列表与 `role="menu"` 语义保持不变。

#### Scenario: 无脚本变更

- **GIVEN** 本变更已部署
- **WHEN** 检查 `frontend.js` 与 `admin.js` 中用户菜单开关相关逻辑
- **THEN** 不存在为本修复而新增的菜单定位或 Portal 逻辑

### Requirement: 收起侧栏时用户菜单左对齐用户头像上方弹出

当应用 shell 处于侧边栏收起状态（`.is-sidebar-collapsed`）时，底部用户头像触发的下拉菜单 MUST 在头像行上方弹出，且菜单左边缘 MUST 与用户头像左边缘对齐；MUST NOT 将菜单向右浮出至侧栏轨道外侧。

#### Scenario: 前台收起侧栏打开用户菜单

- **GIVEN** 用户已打开前台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单出现在头像上方（非侧栏右缘外侧）
- **AND** 菜单左边缘与用户头像左边缘对齐
- **AND** 各菜单项文案以横排可读方式显示（不得出现逐字竖排换行）

#### Scenario: 后台收起侧栏打开用户菜单

- **GIVEN** 用户已打开后台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单出现在头像上方（非侧栏右缘外侧）
- **AND** 菜单左边缘与用户头像左边缘对齐
- **AND** 各菜单项文案以横排可读方式显示（不得出现逐字竖排换行）

#### Scenario: 前台收起侧栏菜单不被播放器遮挡

- **GIVEN** 用户已打开前台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单完整可见且可点击，不被底部 `.studio-player` 遮挡

#### Scenario: 后台收起侧栏菜单不被试听条遮挡

- **GIVEN** 用户已打开后台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单完整可见且可点击，不被底部试听播放器遮挡

### Requirement: 收起侧栏时用户菜单与头像垂直间隙一致

当应用 shell 处于侧边栏收起状态（`.is-sidebar-collapsed`）时，用户菜单底边与用户头像顶边之间的垂直间隙 MUST 与展开侧栏时相同，均为 **6px**（即 `bottom: calc(100% + 6px)`，MUST NOT 额外叠加播放器高度变量）。

#### Scenario: 前台收起侧栏菜单与头像间距

- **GIVEN** 用户已打开前台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单底边与头像顶边之间的垂直间距为 6px
- **AND** 该间距与侧栏展开时打开同一菜单的间距一致

#### Scenario: 后台收起侧栏菜单与头像间距

- **GIVEN** 用户已打开后台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单底边与头像顶边之间的垂直间距为 6px
- **AND** 该间距与侧栏展开时打开同一菜单的间距一致

#### Scenario: 前台展开侧栏基准间距不变

- **GIVEN** 用户已打开前台壳页面且侧栏处于展开状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单底边与头像顶边之间的垂直间距仍为 6px（与变更前一致）

#### Scenario: 后台展开侧栏基准间距不变

- **GIVEN** 用户已打开后台壳页面且侧栏处于展开状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单底边与头像顶边之间的垂直间距仍为 6px（与变更前一致）
