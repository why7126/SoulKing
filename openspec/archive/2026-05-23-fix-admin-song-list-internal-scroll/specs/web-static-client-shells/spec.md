## ADDED Requirements

### Requirement: 后台歌曲管理页列表容器双轴滚动

歌曲管理页表格数据（表头与 tbody 行）的纵向与横向滚动 MUST 仅发生在列表滚动容器（如 `.adm-table-scroll`）内部。当表格内容高度超出容器可视高度时，容器 MUST 出现纵向滚动条并可滚动浏览当前页全部行；当表格列总宽度超出容器可视宽度时，容器 MUST 出现横向滚动条并可滚动浏览全部数据列（含发行日期、元数据、创建时间、更新时间等中间列）。表底分页栏 MUST 位于滚动容器之外、列表区底部，且不随表格内容滚动。

纵向滚动时，表头（`thead`）SHALL 在滚动容器顶部保持可见（sticky），以便用户对照列名。

#### Scenario: 纵向滚动浏览当前页全部行

- **GIVEN** 歌曲管理页已加载且当前页行数超出列表容器可视高度
- **WHEN** 用户在列表滚动容器内向下滚动
- **THEN** 容器出现纵向滚动条（或等价可滚动指示）
- **AND** 用户可滚动至当前页最后一行
- **AND** 表头在滚动过程中保持固定在容器顶部可见
- **AND** 表底分页栏位置不变且仍可见

#### Scenario: 横向滚动浏览全部数据列

- **GIVEN** 歌曲管理页已加载且表格列总宽度大于列表容器宽度
- **WHEN** 用户在列表滚动容器内横向滚动
- **THEN** 容器出现横向滚动条（或等价可滚动指示）
- **AND** 用户可滚动访问中间列（如发行日期、元数据、创建时间、更新时间）
- **AND** 页面级（body 或 `.app-admin-main-wrap`）不出现用于浏览表格列的横向滚动条

#### Scenario: 滚动容器边界不受 display contents 破坏

- **GIVEN** 用户打开歌曲管理页
- **WHEN** 检查列表 DOM 结构
- **THEN** 表格包裹于具备 `overflow: auto`（或等价双轴滚动）的独立容器内
- **AND** 该容器参与 flex 列布局并具备 `min-height: 0`（或等价高度约束），使滚动发生在容器内而非整页

## MODIFIED Requirements

### Requirement: 后台歌曲管理页主区滚动与视口

后台歌曲管理页在标准桌面视口下，浏览器窗口 MUST NOT 因歌曲列表区域而出现整页（`body` 或主内容 wrap）纵向滚动条。列表数据行的纵向滚动 MUST 仅发生在表格容器（如 `.adm-table-scroll`）内部；列表数据列的横向滚动 MUST 仅发生在同一表格容器内部。表底分页栏 MUST 位于表格容器下方、在同一主列布局内，且在不滚动页面的情况下始终可见。

#### Scenario: 视口内无页面级纵滚

- **GIVEN** 用户打开歌曲管理页且曲库有数据
- **WHEN** 用户查看浏览器窗口右侧滚动条
- **THEN** 页面级（body 或 `.app-admin-main-wrap`）不出现用于浏览歌曲列表的纵向滚动条
- **AND** 表格区域内部可纵向滚动以查看更多行

#### Scenario: 视口内无页面级横滚

- **GIVEN** 用户打开歌曲管理页且表格列总宽度大于视口宽度
- **WHEN** 用户查看浏览器窗口底部滚动条
- **THEN** 页面级（body 或 `.app-admin-main-wrap`）不出现用于浏览歌曲列表列内容的横向滚动条
- **AND** 表格区域内部可横向滚动以访问全部列

#### Scenario: 表底分页栏固定在列表区底部

- **GIVEN** 歌曲列表已加载且 `total` 大于 0
- **WHEN** 用户未滚动页面
- **THEN** 表底分页栏（含总数文案与翻页控件）出现在当前视口内列表区域底部
