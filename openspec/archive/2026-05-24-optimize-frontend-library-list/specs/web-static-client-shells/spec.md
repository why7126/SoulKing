## MODIFIED Requirements

### Requirement: 前台壳音乐库歌曲列表列定义

前台壳音乐库歌曲表格 SHALL 包含以下列（从左至右）：**#**、**歌曲**、**原唱**、**作词**、**作曲**、**专辑**、**语言**、**标签**、**格式**、**时长**、**发行日期**、**操作**。

序号列（`#`）SHALL 展示当前页内的行序号（随分页偏移递增，如第 2 页每页 20 条时首行显示 21）。歌曲列 SHALL 仅展示曲目标题及播放态指示（若当前正在播放）；MUST NOT 包含封面图、音符图标、`sk-thumb` 或任何等价歌曲图标/缩略图占位。

操作列 MUST 默认仅展示「更多」触发按钮（文案或图标为「⋯」或等价，含 `aria-label`）；试听、加入歌单、下载 MUST 置于该按钮展开的下拉菜单项中，且 MUST 保留既有权限与禁用逻辑（无网页可试听音频时试听/加入歌单为 disabled 并展示说明）。操作列 MUST NOT 在默认态并排展示多个独立图标按钮；MUST NOT 包含收藏按钮或等价占位控件。

列数据 SHALL 映射歌曲 API 响应字段：`lead_artist`、`lyricists`、`composers`、`album`、`language`、`tags`、`formats`/`file_format`、`duration_ms`、`release_date`。

#### Scenario: 列表展示完整列

- **GIVEN** 用户打开音乐库且曲库有至少一首含完整元数据的歌曲
- **WHEN** 列表渲染完成
- **THEN** 表头依次为 #、歌曲、原唱、作词、作曲、专辑、语言、标签、格式、时长、发行日期、操作
- **AND** 首列 `#` 展示当前页行序号

#### Scenario: 歌曲列无图标占位

- **GIVEN** 用户查看音乐库列表任意数据行
- **WHEN** 用户查看「歌曲」列单元格
- **THEN** 仅可见曲目标题文本及（若正在播放）播放态指示
- **AND** 不存在封面缩略图、音符图标或其它歌曲图标元素

#### Scenario: 元数据字段正确展示

- **GIVEN** 某歌曲 API 响应含 `lead_artist`、`lyricists`、`composers`、`release_date`
- **WHEN** 该歌曲出现在音乐库列表中
- **THEN** 对应单元格展示正确文本（作词/作曲为多值时以可读形式合并展示）
- **AND** 发行日期以日期格式或占位符「—」展示

#### Scenario: 操作列默认仅展示更多按钮

- **GIVEN** 用户查看音乐库列表任意数据行
- **WHEN** 用户查看该行操作列且未展开菜单
- **THEN** 可见且仅可见一个「更多」触发按钮
- **AND** 不存在并排独立的试听、加入歌单、下载图标按钮

#### Scenario: 更多菜单提供前台既有操作

- **GIVEN** 用户查看音乐库列表中某首可网页试听的歌曲
- **WHEN** 用户点击该行「更多」并展开菜单
- **THEN** 菜单中存在试听、加入歌单、下载项
- **WHEN** 用户点击「试听」
- **THEN** 触发与既有行内试听按钮相同的播放行为
- **AND** 不存在收藏（♥）菜单项或按钮

#### Scenario: 无网页试听时菜单项禁用

- **GIVEN** 某歌曲无网页可试听音频
- **WHEN** 用户展开该行「更多」菜单
- **THEN** 试听与加入歌单菜单项为 disabled 态
- **AND** 下载菜单项仍可用（若歌曲可下载）

### Requirement: 前台壳音乐库表格冻结列

当音乐库歌曲表格列总宽度超出列表滚动容器可视宽度时，用户横向滚动表格时 **#** 列与 **歌曲** 列 MUST 保持固定可见（sticky left），**操作** 列 MUST 保持固定可见（sticky right）；行为对齐后台歌曲管理页双侧冻结体验：表头与数据行同步冻结，中间列（原唱至发行日期）随横向滚动移动。

表格 MUST 使用 `border-collapse: separate`（或等价实现）以保证 sticky 列 z-index 在横向滚动时生效。冻结列单元格 MUST 使用不透明背景色覆盖其下方滚动列内容；横向滚动至任意位置时，滚动列的文字或控件 MUST NOT 与冻结列内容发生视觉重叠或「透出」。

操作列在用户横向滚动时 MUST 对表头与每一数据行均采用右侧冻结，使「更多」按钮始终贴在列表滚动容器右缘且可点击。操作列单元格 MUST 保持表格单元格显示类型；按钮与菜单布局 SHALL 应用于单元格内层包裹元素。

#### Scenario: 横向滚动时序号与歌曲列固定

- **GIVEN** 用户处于音乐库视图且表格需横向滚动
- **WHEN** 用户在 `.studio-library-table-wrap` 内向右滚动
- **THEN** # 列与歌曲列仍固定在容器左侧可见
- **AND** 原唱及后续中间列随滚动移出或进入视口

#### Scenario: 横向滚动时操作列固定

- **GIVEN** 用户处于音乐库视图且表格需横向滚动
- **WHEN** 用户将表格横向滚动到任意位置
- **THEN** 操作列仍固定在容器右侧可见
- **AND** 用户能点击该行「更多」按钮而无需先滚回最右侧

#### Scenario: 冻结列 hover 与背景

- **GIVEN** 用户横向滚动后鼠标悬停某数据行
- **WHEN** 该行处于 hover 态
- **THEN** 左侧与右侧冻结列单元格背景与该行 hover 样式一致，不出现透底或错位

#### Scenario: 横向滚动时冻结列不透底

- **GIVEN** 音乐库表格中间列含较长文本且需横向滚动
- **WHEN** 用户横向滚动使某中间列文字经过左侧或右侧冻结列区域
- **THEN** 冻结列下方不可见该中间列文字或控件
- **AND** 冻结列内序号、歌曲名或「更多」按钮清晰可读、无叠字
