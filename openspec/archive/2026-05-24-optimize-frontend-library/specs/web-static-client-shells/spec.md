## MODIFIED Requirements

### Requirement: 前台壳音乐库内容区布局与筛选

前台壳内「音乐库」主内容区（`#songBrowseSection`）SHALL 展示单一歌曲列表视图，MUST NOT 包含「全部歌曲 / 我喜欢的 / 最近播放」Tab 栏或等价视图切换控件，MUST NOT 包含「智能排序」或等价占位排序入口。

内容区 SHALL 提供与后台歌曲管理页一致的工具栏布局：同一行内包含搜索框、「更多筛选」按钮与「重置」按钮（有活跃筛选条件时显示重置）。搜索框 placeholder 与清空按钮行为 SHALL 与后台歌曲管理搜索框等价（支持关键字搜索歌曲/艺人/专辑/标签等）。

用户点击「更多筛选」时 SHALL 展开/收起筛选面板；面板内 SHALL 为原唱、作词、作曲、标签、格式、语言六个维度提供可搜索的多选下拉，布局与交互模式对齐后台 `adm-filters-panel`。筛选条件 MUST 通过曲库列表 API 查询参数提交并在服务端生效。

在音乐库视图激活时，整个顶栏区域（`.studio-top-header`）SHALL 隐藏，避免空白占空间及与内容区搜索重复；用户通过键盘快捷键（如 ⌘K / Ctrl+K）时 SHALL 聚焦内容区搜索框（`#libraryKeywordInput`）。

#### Scenario: 音乐库无 Tab 与智能排序

- **GIVEN** 用户打开前台壳并进入音乐库视图
- **WHEN** 用户查看音乐库内容区标题下方区域
- **THEN** 不存在「全部歌曲」「我喜欢的」「最近播放」Tab 控件
- **AND** 不存在「智能排序」按钮

#### Scenario: 搜索与更多筛选同一行

- **GIVEN** 用户打开前台壳并进入音乐库视图
- **WHEN** 用户查看筛选工具栏
- **THEN** 搜索输入框与「更多筛选」按钮位于同一工具栏行内
- **AND** 布局模式与后台歌曲管理页工具栏一致（搜索区可伸展，筛选按钮靠行内排列）

#### Scenario: 展开六维筛选面板

- **GIVEN** 用户处于音乐库视图且筛选面板未展开
- **WHEN** 用户点击「更多筛选」
- **THEN** 展开面板显示原唱、作词、作曲、标签、格式、语言六个多选筛选控件
- **AND** 用户选择条件后列表按服务端过滤结果刷新

#### Scenario: 音乐库视图隐藏整个顶栏

- **GIVEN** 用户处于音乐库视图
- **WHEN** 用户查看主内容区上方
- **THEN** `.studio-top-header` 不可见且不占用垂直布局空间
- **AND** 内容区工具栏搜索框可用

#### Scenario: 重置筛选

- **GIVEN** 用户已设置至少一项筛选条件
- **WHEN** 用户点击「重置」
- **THEN** 所有筛选控件清空
- **AND** 列表恢复为无筛选条件下的结果

### Requirement: 前台壳音乐库歌曲列表列定义

前台壳音乐库歌曲表格 SHALL 包含以下列（从左至右）：**#**、**歌曲**、**原唱**、**作词**、**作曲**、**专辑**、**语言**、**标签**、**格式**、**时长**、**发行日期**、**操作**。

序号列（`#`）SHALL 展示当前页内的行序号（随分页偏移递增，如第 2 页每页 20 条时首行显示 21）。歌曲列 SHALL 展示曲目标题及播放态指示（若当前正在播放）。操作列 SHALL 包含试听、加入歌单、下载等前台既有行内操作，MUST NOT 包含收藏按钮或等价占位控件。

列数据 SHALL 映射歌曲 API 响应字段：`lead_artist`、`lyricists`、`composers`、`album`、`language`、`tags`、`formats`/`file_format`、`duration_ms`、`release_date`。

#### Scenario: 列表展示完整列

- **GIVEN** 用户打开音乐库且曲库有至少一首含完整元数据的歌曲
- **WHEN** 列表渲染完成
- **THEN** 表头依次为 #、歌曲、原唱、作词、作曲、专辑、语言、标签、格式、时长、发行日期、操作
- **AND** 首列 `#` 展示当前页行序号

#### Scenario: 元数据字段正确展示

- **GIVEN** 某歌曲 API 响应含 `lead_artist`、`lyricists`、`composers`、`release_date`
- **WHEN** 该歌曲出现在音乐库列表中
- **THEN** 对应单元格展示正确文本（作词/作曲为多值时以可读形式合并展示）
- **AND** 发行日期以日期格式或占位符「—」展示

#### Scenario: 操作列保留前台能力且无收藏

- **GIVEN** 用户查看音乐库列表中某首可网页试听的歌曲
- **WHEN** 用户查看该行操作列
- **THEN** 存在试听按钮且可触发播放
- **AND** 存在加入歌单与下载等前台既有操作入口
- **AND** 不存在收藏（♥）按钮

## ADDED Requirements

### Requirement: 前台壳音乐库服务端分页与页脚信息

前台音乐库列表数据 MUST 通过曲库列表 API 的 `offset` 与 `limit` 分页获取，不得依赖一次性拉取固定上限（如 500）后在客户端切片作为唯一分页来源。切换页码或每页条数时 MUST 重新请求当前页数据，并使用 API 响应中的 `total` 作为分页总数；客户端渲染列表时 MUST NOT 用当前页 `items.length` 覆盖 `total`。

页脚分页区域 MUST 始终展示总数与分页控件；SHALL 额外展示当前页范围与页码信息，例如「显示 21–40，共 312 首」与「第 2 / 16 页」（文案可合并为一行或分两处展示）。

筛选条件变更时 SHALL 将页码重置为 1 并重新请求。

#### Scenario: 翻页重新请求服务端数据

- **GIVEN** 曲库筛选结果 `total` 大于每页条数
- **WHEN** 用户点击「下一页」或某一页码
- **THEN** 客户端以新的 `offset` 与 `limit` 请求 `/songs`
- **AND** 列表展示对应页的数据行

#### Scenario: 修改每页条数

- **GIVEN** 用户处于音乐库列表页脚
- **WHEN** 用户将每页条数从 20 改为 50
- **THEN** 页码重置为 1
- **AND** 以 `limit=50` 重新请求并刷新列表

#### Scenario: 页脚展示范围与页码

- **GIVEN** 当前为第 2 页、每页 20 条、筛选后 `total` 为 312
- **WHEN** 列表加载成功
- **THEN** 页脚可见文案包含当前页条目范围（如 21–40）
- **AND** 可见总条数 312 与页码信息（如第 2 / 16 页）

#### Scenario: 仅一页时仍展示分页信息

- **GIVEN** 筛选后 `total` 小于等于每页条数
- **WHEN** 列表渲染完成
- **THEN** 页脚仍展示总数与页码（如第 1 / 1 页）
- **AND** 「下一页」控件为禁用态

### Requirement: 前台壳音乐库表格冻结列

当音乐库歌曲表格列总宽度超出列表滚动容器可视宽度时，用户横向滚动表格时 **#** 列与 **歌曲** 列 MUST 保持固定可见（sticky），行为对齐后台歌曲管理页冻结列体验：表头与数据行同步冻结，滚动列从第三列（原唱）起横向移动。

#### Scenario: 横向滚动时序号与歌曲列固定

- **GIVEN** 用户处于音乐库视图且表格需横向滚动
- **WHEN** 用户在 `.studio-library-table-wrap` 内向右滚动
- **THEN** # 列与歌曲列仍固定在容器左侧可见
- **AND** 原唱及后续列随滚动移出或进入视口

#### Scenario: 冻结列 hover 与背景

- **GIVEN** 用户横向滚动后鼠标悬停某数据行
- **WHEN** 该行处于 hover 态
- **THEN** 冻结列单元格背景与该行 hover 样式一致，不出现透底或错位

### Requirement: 前台壳底部播放器播放模式选择

底部播放器 transport 区域 SHALL 提供带中文标签的播放模式下拉（或等价 popover），至少包含：列表循环、单曲循环、随机播放、顺序播放。用户选择某一模式时 MUST 更新播放器 `state.playMode` 并影响下一首/循环行为。

MUST NOT 依赖仅 emoji 图标循环切换作为唯一模式入口。独立的随机播放快捷按钮 MAY 省略，以避免与下拉中「随机播放」重复。

#### Scenario: 通过下拉切换列表循环与单曲循环

- **GIVEN** 用户正在前台壳底部播放器区域
- **WHEN** 用户在下拉中选择「单曲循环」
- **THEN** 当前曲目播放结束后重复播放同一首
- **AND** 下拉显示当前选中项为「单曲循环」

#### Scenario: 通过下拉切换随机播放

- **GIVEN** 播放队列中有多首可试听曲目
- **WHEN** 用户在下拉中选择「随机播放」
- **THEN** 点击「下一首」时从队列中随机选取可播放曲目（与既有随机逻辑一致）

### Requirement: 前台壳未实现占位控件隐藏

在收藏、音质切换等能力未接入前，前台壳 MUST NOT 展示以下占位控件：音乐库列表操作列收藏按钮、底部播放器左侧收藏（♥）按钮、右侧详情面板收藏按钮、底部播放器「调」（音质）按钮。

#### Scenario: 音乐库列表无收藏按钮

- **GIVEN** 用户查看音乐库歌曲列表
- **WHEN** 用户查看任意行操作列
- **THEN** 不存在收藏按钮

#### Scenario: 播放器与详情无收藏与音质占位

- **GIVEN** 用户打开前台壳
- **WHEN** 用户查看底部播放器与右侧详情面板
- **THEN** 不存在播放器左侧 ♥ 收藏按钮
- **AND** 不存在详情面板 ♥ 收藏按钮
- **AND** 不存在底部播放器「调」音质按钮
