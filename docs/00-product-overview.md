# 产品总览

ProjectSoulKing 是私有化个人音乐管理系统，用于把本地音频文件导入对象存储，维护歌曲元数据、歌词、歌单、用户资料和后台参考数据。

## 核心用户

| 用户 | 目标 |
|---|---|
| 个人音乐库维护者 | 扫描本地目录，去重导入音频，管理歌曲信息和歌单 |
| 管理员 | 维护用户、艺人、标签、语言、风格、存储路径和重复歌曲 |

## 核心能力

- 本地 `import/` 音频扫描与 MinIO 对象存储导入。
- 歌曲、音频文件、歌词、艺人、标签、语言、风格和歌单管理。
- 前台播放、下载、搜索、筛选、歌单与个人资料维护。
- 后台音乐管理、参考数据管理、用户管理和批量治理。
- 用户认证、管理员保护、头像上传和密码修改。

## 当前范围

| 类型 | 内容 |
|---|---|
| 当前包含 | Web 前台、Web 后台、FastAPI REST、SQLite、MinIO 单桶、macOS 打包辅助 |
| 暂不包含 | 公开注册、多租户、移动端、小程序、独立算法服务、在线视频管理 |
| 外部依赖 | 并列项目 `ProjectMinio` 提供对象存储 |

正式系统能力以 `openspec/specs/` 为事实源；开发中变更以 `openspec/changes/`、`issues/` 和 `iterations/` 为事实源。
