# 数据库设计

SQLite 是当前主库，SQLAlchemy 模型位于 `app/models.py`，数据库连接与启动迁移位于 `app/database.py` 和启动流程。

## 主要数据域

| 数据域 | 说明 |
|---|---|
| 用户与认证 | 用户账号、密码哈希、角色、昵称、头像对象键 |
| 曲库 | 歌曲、音频文件、标题、时长、格式、sha256、对象键 |
| 参考数据 | 艺人、标签、语言、风格及其关联关系 |
| 歌词与播放 | 歌词文本、播放候选文件、下载/流式访问 |
| 歌单 | 歌单和歌单歌曲关联 |
| 迁移标记 | `_schema_migrations` 记录启动兼容迁移 |

## 迁移原则

- 结构变更必须先有 OpenSpec Change。
- 启动兼容迁移必须幂等，并记录到迁移标记表。
- 不在提交中包含 `data/music.db`、`data/test-auth.db` 或真实用户数据。
- 删除字段、改唯一约束、批量迁移对象键时必须提供回滚或预检说明。
