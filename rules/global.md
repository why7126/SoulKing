# 全局规则

- 默认使用简体中文沟通和撰写治理文档。
- 需求、BUG、Sprint、OpenSpec、验证结果必须写入仓库文件，不以聊天记录作为唯一事实源。
- 行为变化、接口变化、数据结构变化、权限变化、部署变化必须先建立 OpenSpec Change。
- 修改前读取 `AGENTS.md` 指定的最小规则和任务相关规则。
- 不提交 `.env`、运行时数据库、个人媒体文件、真实密钥和临时大文件。
