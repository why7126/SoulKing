## MODIFIED Requirements

### Requirement: 后台歌曲管理页列表操作按钮

操作列 SHALL 提供编辑、播放、下载三类主操作：编辑打开编辑抽屉；播放仅在存在可浏览器试听的音频时可用；下载打开格式选择或直链下载流程（与现有单曲下载行为一致）。删除等破坏性操作 MAY 保留在「更多」菜单中。

操作列在用户横向滚动表格时 MUST 对**表头与每一数据行**均采用右侧冻结（`position: sticky; right: 0` 或等价实现），使主操作按钮始终贴在列表滚动容器右缘且可点击。操作列单元格 MUST 保持表格单元格显示类型（不得对 `<td class="col-actions">` 使用 `display: flex` 或 `display: block` 等破坏 `table-cell` 的样式）；按钮组的 flex 布局 SHALL 应用于单元格内层包裹元素。列宽 MUST 足以同时展示编辑、播放、下载、更多四个主控件，避免裁切或重叠不可点。

#### Scenario: 可播放歌曲显示播放

- **GIVEN** 列表行对应歌曲存在可 Web 试听的音频变体
- **WHEN** 用户查看操作列
- **THEN** 播放操作可用
- **AND** 激活后发起试听（与现有 `play` 流程一致）

#### Scenario: 不可播放时禁用或隐藏播放

- **GIVEN** 列表行对应歌曲无可 Web 试听变体
- **WHEN** 用户查看操作列
- **THEN** 播放操作不可用或不出现在主操作区

#### Scenario: 横向滚动后仍可见操作与更新时间

- **GIVEN** 表格列总宽度大于表格容器宽度
- **WHEN** 用户将表格横向滚动到最右（或操作列已冻结在右侧）
- **THEN** 用户能看到「更新时间」列内容
- **AND** 用户能看到并点击操作列中的编辑、下载等主操作按钮

#### Scenario: 横向滚动中间位置时各行操作按钮仍冻结

- **GIVEN** 表格列总宽度大于列表滚动容器宽度，且用户已将横向滚动条置于中间位置（既未滚到最左也未滚到最右，中间列如「发行日期」可见）
- **WHEN** 用户查看任意可见数据行的操作列
- **THEN** 该行编辑、播放、下载、更多按钮仍出现在滚动容器右缘的操作列区域内
- **AND** 与表头「操作」列横向对齐
- **AND** 用户可点击其中任一主操作按钮
