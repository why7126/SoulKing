## ADDED Requirements

### Requirement: 后台歌曲管理页编辑抽屉宽度

后台壳内歌曲管理页右侧编辑面板（`#adminEditPanel` / `.admin-edit-panel`）在打开状态（`.is-open`）时，宽度 MUST 大于变更前默认值（`380px`），并通过 CSS 变量（如 `--adm-edit-w`）统一配置，以便容纳原唱/作词/作曲多选控件与标签多选下拉。窄屏下宽度 MUST 不超过视口宽度。

#### Scenario: 打开编辑面板时有足够宽度

- **GIVEN** 用户从歌曲列表点击「编辑」打开右侧编辑面板
- **WHEN** 面板处于 `.is-open` 状态
- **THEN** 面板宽度不小于 `460px`（或由 `--adm-edit-w` 设定的等价值）
- **AND** 原唱、作词、作曲三个多选触发器可在同一行或相邻行内完整显示而不严重重叠

### Requirement: 后台歌曲管理页编辑抽屉原唱作词作曲字段

编辑抽屉主表单 MUST 提供 **原唱**、**作词**、**作曲** 三个独立字段（不得使用单一「艺人」标签合并原唱）。三个字段 MUST 使用与编辑抽屉「语言」字段相同的多选交互组件（`multi-select`）：支持关键字模糊搜索选项、多选勾选/取消、在搜索框输入无完全匹配项时创建并选中、触发器以 chip 展示已选项。原唱对应艺人类型「歌手」；作词、作曲对应艺人类型「作词」「作曲」。作词、作曲字段 MUST 位于主表单可见区域，不得仅存在于 `adm-hidden-filters` 隐藏区。

#### Scenario: 打开编辑抽屉显示三个艺人字段

- **GIVEN** 用户打开某首歌曲的编辑抽屉
- **WHEN** 抽屉元数据表单渲染完成
- **THEN** 用户可见标签为「原唱」「作词」「作曲」的三个多选控件
- **AND** 不存在标签为「艺人」的单一合并字段

#### Scenario: 原唱多选模糊搜索与新建

- **GIVEN** 编辑抽屉已打开且艺人管理中存在名称包含「周」的歌手
- **WHEN** 用户在原唱多选搜索框输入「周」
- **THEN** 下拉列表显示名称模糊匹配的歌手选项
- **WHEN** 用户输入不存在的艺人名并选择「创建并添加」
- **THEN** 系统创建该艺人（类型含歌手）并加入原唱已选集合

#### Scenario: 保存后作词作曲回显

- **GIVEN** 用户为某曲选择了作词人 A、作曲人 B 并保存
- **WHEN** 用户再次打开该曲编辑抽屉
- **THEN** 作词、作曲多选触发器分别展示 A、B（或等价 chip）

### Requirement: 后台歌曲管理页编辑抽屉标签多选

编辑抽屉中的「标签」字段 MUST 使用与「语言」字段相同的多选交互（`multi-select`），取代平铺 checkbox 列表。行为 MUST 包括：从标签管理列表（`/tags`）加载选项、关键字模糊搜索、多选、搜索框内输入新建标签（`POST /tags`）并自动选中。保存元数据时 MUST 提交所选 `tag_ids`（或与现有保存 API 等价的标签 id 列表）。

#### Scenario: 标签模糊搜索

- **GIVEN** 标签管理中存在「现场」与「录音室」
- **WHEN** 用户在编辑抽屉标签多选中输入「现」
- **THEN** 下拉仅显示名称模糊匹配「现」的标签（如「现场」）

#### Scenario: 新建标签并选中

- **GIVEN** 标签管理中不存在「Demo」
- **WHEN** 用户在标签搜索框输入「Demo」并确认创建
- **THEN** 「Demo」出现在标签管理数据中
- **AND** 该标签处于当前歌曲已选标签集合中

### Requirement: 后台歌曲管理页编辑抽屉格式只读聚合

编辑抽屉 MUST NOT 提供用户可编辑的「格式」表单控件（无 text input、select 等用于修改格式的字段）。该曲关联的 **全部** 音频文件（`detail.files` 或等价结构）的 `format` MUST 自动聚合为只读展示（如 `MP3 / FLAC`），去重后以大写扩展名形式呈现；当无任何音频文件时展示占位（如「—」）。添加、删除或替换音频文件后，只读格式展示 MUST 同步更新，且无需用户保存元数据即可反映文件列表变化。

#### Scenario: 多格式音频只读展示

- **GIVEN** 某曲关联 `song.mp3`（format mp3）与 `song.flac`（format flac）
- **WHEN** 用户打开编辑抽屉
- **THEN** 抽屉内可见只读格式信息包含 MP3 与 FLAC（顺序不限，须去重）
- **AND** 不存在可编辑的格式输入框

#### Scenario: 添加音频文件后格式更新

- **GIVEN** 编辑抽屉已打开且当前仅有一个 MP3 文件
- **WHEN** 用户通过「添加文件」成功上传 FLAC
- **THEN** 只读格式展示更新为包含 MP3 与 FLAC

#### Scenario: 无音频文件

- **GIVEN** 某曲无任何关联音频文件
- **WHEN** 用户打开编辑抽屉
- **THEN** 只读格式展示为占位符或空状态文案
- **AND** 用户无法通过格式字段输入修改格式
