## ADDED Requirements

### Requirement: 收起侧栏时用户菜单左对齐用户头像上方弹出

当应用 shell 处于侧边栏收起状态（`.is-sidebar-collapsed`）时，底部用户头像触发的下拉菜单 MUST 在头像行上方弹出，且菜单左边缘 MUST 与用户头像左边缘对齐；MUST NOT 将菜单向右浮出至侧栏轨道外侧。

#### Scenario: 前台收起侧栏打开用户菜单

- **GIVEN** 用户已打开前台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单出现在头像上方（非侧栏右缘外侧）
- **AND** 菜单左边缘与用户头像左边缘对齐
- **AND** 各菜单项文案以横排可读方式显示（不得出现逐字竖排换行）

#### Scenario: 后台收起侧栏打开用户菜单

- **GIVEN** 用户已打开后台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单出现在头像上方（非侧栏右缘外侧）
- **AND** 菜单左边缘与用户头像左边缘对齐
- **AND** 各菜单项文案以横排可读方式显示（不得出现逐字竖排换行）

#### Scenario: 前台收起侧栏菜单不被播放器遮挡

- **GIVEN** 用户已打开前台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单完整可见且可点击，不被底部 `.studio-player` 遮挡

#### Scenario: 后台收起侧栏菜单不被试听条遮挡

- **GIVEN** 用户已打开后台壳页面且侧栏处于收起状态
- **WHEN** 用户点击底部用户头像打开菜单
- **THEN** 菜单完整可见且可点击，不被底部试听播放器遮挡

## REMOVED Requirements

### Requirement: 收起侧栏时用户菜单向右浮出轨道

**Reason**: 向右浮出导致菜单与底部播放器在视口上重叠；改为头像上方左对齐弹出，从布局上避开播放器。

**Migration**: 移除 `left: calc(100% + 8px)` 规则，改用 `left: calc(50% - 18px)` 左对齐头像。

### Requirement: 收起侧栏时用户菜单显示在底部播放器之上

**Reason**: 新布局通过头像上方弹出 + 左对齐头像，从空间上避开底部播放器区域，不再依赖提升 z-index 解决层叠遮挡。

**Migration**: 收起态菜单保持默认 `z-index: 30`；验收改为确认菜单在布局上不被播放器遮挡，而非验证 z-index 数值高于播放器。
