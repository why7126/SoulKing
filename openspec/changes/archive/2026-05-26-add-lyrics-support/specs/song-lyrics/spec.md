## ADDED Requirements

### Requirement: 歌词文件记录形态

系统 SHALL 将 LRC 歌词存储为与歌曲关联的 `SongFile` 记录：`format` 为 `lrc`（不含点号、小写），`is_playable_web` 为 false，`is_lossless` 为 false；对象存放在音乐桶中，对象键由现有音乐对象键计算规则生成且扩展名为 `lrc`。

每首歌曲在任意时刻 SHALL 至多存在一条「当前有效」的 LRC 记录；当新的 LRC 通过扫描侧车或上传接口关联到该曲时，系统 MUST 删除该曲下其它 `format=lrc` 的记录及其对象存储对象后再写入新记录。

#### Scenario: 歌词记录不可用于浏览器试听

- **GIVEN** 某歌曲下存在一条 `format=lrc` 的文件记录
- **WHEN** 客户端请求该曲试听信息或按推荐规则择轨
- **THEN** 该记录不得被选为试听或下载的音频变体

#### Scenario: 替换歌词后仅保留一条 LRC

- **GIVEN** 歌曲 A 已有关联 LRC 记录 R1
- **WHEN** 客户端为歌曲 A 成功上传新的 LRC 文件
- **THEN** 记录 R1 及其对象被删除
- **AND** 歌曲 A 下仅存在一条新的 `format=lrc` 记录

### Requirement: 按歌曲读取歌词

客户端 SHALL 可请求指定歌曲的歌词；服务端 MUST 校验歌曲存在。若该曲无 LRC 记录，则 MUST 返回表示无歌词的响应（HTTP 404 或约定空载荷，实现须在 API 文档中固定一种）。

若存在 LRC，服务端 MUST 从对象存储读取文本内容（UTF-8 优先；无法解码时按实现约定的回退策略），并在响应中返回原始文本及解析后的行列表。行列表中每一项 SHALL 包含毫秒级时间戳与非空或可为空的文本字段；无法解析时间标签的行可省略或归入时间戳为零的元数据行，行为须在实现中一致。

#### Scenario: 歌曲存在且有关联 LRC

- **GIVEN** 歌曲存在且有一条有效 LRC 记录
- **WHEN** 客户端请求该曲歌词
- **THEN** 响应包含原始歌词文本
- **AND** 响应包含解析后的时间行列表（可为空列表若解析失败）

#### Scenario: 歌曲存在但无 LRC

- **GIVEN** 歌曲存在且无任何 `format=lrc` 记录
- **WHEN** 客户端请求该曲歌词
- **THEN** 返回表示无歌词的错误或空载荷（与实现约定一致）

#### Scenario: 歌曲不存在

- **GIVEN** 歌曲标识不存在
- **WHEN** 客户端请求该曲歌词
- **THEN** 返回未找到类错误

### Requirement: 按歌曲上传或替换歌词

客户端可向指定歌曲提交单个 `.lrc` 文件（多部分表单）；后缀 MUST 为 `.lrc`（大小写不敏感）。文件大小 MUST 不超过实现设定的上限（建议不超过 512KB）。成功后执行「每曲一条有效 LRC」替换逻辑，并返回与读取歌词相同结构的响应。

#### Scenario: 成功上传 LRC

- **GIVEN** 目标歌曲存在，且上传文件后缀为 `.lrc` 且未超大小限制
- **WHEN** 客户端提交上传请求
- **THEN** 对象存储中存在新对象，曲库中存在该曲一条 `format=lrc` 记录
- **AND** 响应包含歌词文本与解析行列表

#### Scenario: 非 LRC 后缀被拒绝

- **GIVEN** 上传文件后缀不是 `.lrc`
- **WHEN** 客户端提交上传请求
- **THEN** 返回表示请求无效的错误

#### Scenario: 歌曲不存在

- **GIVEN** 歌曲标识不存在
- **WHEN** 客户端提交上传请求
- **THEN** 返回未找到类错误

### Requirement: 按歌曲删除歌词

客户端可请求删除指定歌曲的当前有效 LRC；若存在记录与对象，则 MUST 删除对象存储对象并删除数据库记录。若本不存在 LRC，则返回未找到类错误或成功无操作（实现须固定一种）。

#### Scenario: 删除已有关联 LRC 的歌曲

- **GIVEN** 歌曲存在且有一条有效 LRC
- **WHEN** 客户端请求删除歌词
- **THEN** 该 LRC 记录与对象均被移除
- **AND** 再次读取歌词得到无歌词响应

#### Scenario: 删除无 LRC 的歌曲

- **GIVEN** 歌曲存在但无 LRC 记录
- **WHEN** 客户端请求删除歌词
- **THEN** 返回与实现约定一致（未找到或成功无操作）

### Requirement: LRC 时间标签解析

服务端解析器 SHALL 支持常见 LRC 行格式 `[mm:ss.xx]` 与 `[mm:ss]`，并将时间换算为自曲目开始的毫秒数。同一行内多个时间标签应对应多行条目或取第一个标签，行为须在实现中一致并写入 Notes。

#### Scenario: 标准时间标签被解析

- **GIVEN** 歌词文本包含行 `[00:12.50]第一句歌词`
- **WHEN** 服务端解析该文本
- **THEN** 行列表中包含时间戳 12500 毫秒且文本为 `第一句歌词` 的条目
