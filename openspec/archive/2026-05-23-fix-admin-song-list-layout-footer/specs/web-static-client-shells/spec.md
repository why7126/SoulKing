## ADDED Requirements

### Requirement: 后台歌曲管理页主区滚动与视口

后台歌曲管理页在标准桌面视口下，浏览器窗口 MUST NOT 因歌曲列表区域而出现整页（`body` 或主内容 wrap）纵向滚动条。列表数据行的纵向滚动 MUST 仅发生在表格容器（如 `.adm-table-scroll`）内部。表底分页栏 MUST 位于表格容器下方、在同一主列布局内，且在不滚动页面的情况下始终可见。

#### Scenario: 视口内无页面级纵滚

- **GIVEN** 用户打开歌曲管理页且曲库有数据
- **WHEN** 用户查看浏览器窗口右侧滚动条
- **THEN** 页面级（body 或 `.app-admin-main-wrap`）不出现用于浏览歌曲列表的纵向滚动条
- **AND** 表格区域内部可纵向滚动以查看更多行

#### Scenario: 表底分页栏固定在列表区底部

- **GIVEN** 歌曲列表已加载且 `total` 大于 0
- **WHEN** 用户未滚动页面
- **THEN** 表底分页栏（含总数文案与翻页控件）出现在当前视口内列表区域底部

## MODIFIED Requirements

### Requirement: 后台歌曲管理页服务端分页与总数展示

歌曲管理页列表数据 MUST 通过曲库列表 API 的 `offset` 与 `limit` 分页获取，不得依赖一次性拉取固定上限（如 500）后在客户端切片作为唯一分页来源。页脚分页控件切换页码或每页条数时 MUST 重新请求当前页数据。

表底栏 SHALL 为单行布局：**左侧**展示当前筛选条件下的总数文案（如「共 N 首」或「共 N 首（已筛选）」）；**右侧**展示翻页控件（上一页、页码、下一页、每页条数）。表底 MUST NOT 包含批量编辑、批量标签、批量删除等批量操作按钮或「未选择项目」类表底批量区（批量操作保留在页面顶部工具栏）。

无论是否应用筛选，只要列表请求成功且接口返回的 `total` 已定义，表底 MUST 展示总数文案与分页控件（含仅一页时的页码展示）。

#### Scenario: 翻页请求服务端

- **GIVEN** 筛选后 `total` 大于每页条数
- **WHEN** 用户点击下一页
- **THEN** 客户端以更新后的 `offset` 请求列表 API
- **AND** 表格仅展示该页 `items`

#### Scenario: 展示筛选总数与全库总数

- **GIVEN** 全库 1000 首，当前筛选命中 42 首
- **WHEN** 列表加载完成
- **THEN** 表底左侧显示共 42 首（或等价文案）
- **AND** 顶部音乐总数显示 1000

#### Scenario: 筛选变更重置页码

- **GIVEN** 用户当前在第 3 页
- **WHEN** 用户变更任一快速筛选或关键词
- **THEN** 页码重置为 1
- **AND** 列表与 `total` 反映新筛选条件

#### Scenario: 未筛选时仍展示分页栏

- **GIVEN** 用户未设置任何筛选条件且曲库至少有 1 首歌曲
- **WHEN** 列表加载完成
- **THEN** 表底左侧显示共 N 首（N 为当前 `total`）
- **AND** 表底右侧显示翻页控件（含当前页码）

#### Scenario: 表底无批量操作区

- **GIVEN** 用户已勾选若干歌曲行
- **WHEN** 用户查看表底栏
- **THEN** 表底不出现批量编辑、批量删除等按钮
- **AND** 顶部工具栏仍可提供批量下载、批量删除等能力（若已实现）

### Requirement: 后台歌曲管理页列表操作按钮

操作列 SHALL 提供编辑、播放、下载三类主操作：编辑打开编辑抽屉；播放仅在存在可浏览器试听的音频时可用；下载打开格式选择或直链下载流程（与现有单曲下载行为一致）。删除等破坏性操作 MAY 保留在「更多」菜单中。

操作列与「更新时间」列在用户横向滚动表格时 MUST 仍可通过表格区域滚动访问；实现上 SHOULD 对操作列采用右侧冻结（sticky）并保证列宽足以同时展示主操作按钮，避免按钮被裁切或重叠不可点。

#### Scenario: 可播放歌曲显示播放

- **GIVEN** 列表行对应歌曲存在可 Web 试听的音频变体
- **WHEN** 用户查看操作列
- **THEN** 播放操作可用
- **AND** 激活后发起试听（与现有 `play` 流程一致）

#### Scenario: 不可播放时禁用或隐藏播放

- **GIVEN** 列表行对应歌曲无可 Web 试听变体
- **WHEN** 用户查看操作列
- **THEN** 播放操作不可用或不出现在主操作区

#### Scenario: 横向滚动后仍可见操作与更新时间

- **GIVEN** 表格列总宽度大于表格容器宽度
- **WHEN** 用户将表格横向滚动到最右（或操作列已冻结在右侧）
- **THEN** 用户能看到「更新时间」列内容
- **AND** 用户能看到并点击操作列中的编辑、下载等主操作按钮
