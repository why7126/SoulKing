## ADDED Requirements

### Requirement: 后台歌曲管理页快速筛选可搜索多选

后台壳内歌曲管理页的「更多筛选」面板 SHALL 为原唱、作词、作曲、标签、格式、语言六个维度提供可搜索的多选下拉；用户 MUST 能通过关键字模糊匹配选项，并勾选或取消勾选多项；同一维度内多选为 OR，不同维度之间为 AND。

#### Scenario: 勾选后状态保持

- **GIVEN** 用户已打开「更多筛选」并展开某一维度的下拉
- **WHEN** 用户勾选或取消勾选某一选项
- **THEN** 该选项的勾选状态立即反映在 checkbox 上
- **AND** 关闭并再次打开下拉后勾选状态与之一致
- **AND** 触发器文案反映当前选中（未选时显示维度名称，选中一项时显示该项名称，选中多项时显示合并文案或计数）

#### Scenario: 搜索过滤选项

- **GIVEN** 某维度下拉已展开且存在多个可选项
- **WHEN** 用户在搜索框输入关键字
- **THEN** 仅显示标签或值与关键字模糊匹配的选项
- **AND** 对可见选项的勾选/取消勾选仍正确更新筛选结果

#### Scenario: 筛选结果更新

- **GIVEN** 用户已在至少一个维度选中一个或多个选项
- **WHEN** 选中集合发生变化
- **THEN** 歌曲列表仅显示满足各维度 OR/AND 规则的歌曲
- **AND** 「重置」按钮可见且可清空所有快速筛选与关键词

#### Scenario: 翻页不重建筛选项

- **GIVEN** 用户已在快速筛选中选中若干选项
- **WHEN** 用户切换列表页码或修改每页条数
- **THEN** 快速筛选的选中状态与触发器文案保持不变
- **AND** 下拉选项列表不因仅表格重绘而被清空或重置

#### Scenario: 曲库数据变更后刷新选项

- **GIVEN** 曲库歌曲集合或标签等选项来源发生变更（如扫描完成、重新加载歌曲列表）
- **WHEN** 客户端完成数据刷新
- **THEN** 各维度下拉选项列表更新为与新数据一致的集合
- **AND** 仍保留当前仍存在于新选项列表中的已选值

#### Scenario: 单选项维度可有效勾选

- **GIVEN** 某筛选维度在当前曲库中仅有一个可选项
- **WHEN** 用户勾选该唯一选项
- **THEN** 该选项保持勾选状态
- **AND** 列表按该条件过滤
- **AND** 触发器显示该选项名称而非仅显示维度名称
