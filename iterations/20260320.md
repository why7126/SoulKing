## 2. 下载：多格式、ZIP、命名与时区

### 行为概览

- **单曲**：可选多种格式；仅一个文件时直接下载；多个文件时打 ZIP。
- **批量（后台）**：`POST /admin/songs/batch-download`，body `{ song_ids, formats }`；总文件数为 1 时直链，大于 1 时为 ZIP。
- **包内音频文件名**：`{歌曲名}-{原唱}.{格式}`（非法路径字符已处理）。
- **播放接口**：`PlayResponse.download_url` 指向 `GET /songs/{id}/download`（无 query 时服务端选推荐的一条）。

### ZIP 外层文件名

- **单曲多文件**：`{歌曲名}-{原唱}-{时间戳}.zip`
- **批量多文件**：`music-songs-batch-{时间戳}.zip`
- **时间戳**：`download_zip_timestamp_tag()` — `yyyyMMddHHmmss` + 5 位亚秒（微秒//10），时区为 **Asia/Shanghai**（`zoneinfo` + 依赖 **tzdata**）。

### 后台前端

- 表格「下载」、批量下载：格式多选弹窗（与逻辑同）；批量走 `fetch` + Blob。
- **已移除**编辑抽屉内「添加文件」旁的「下载…」按钮；列表菜单与每条音频图标下载仍保留。

### 前台

- 与后台**单曲下载**一致：多格式弹窗、`GET /songs/{id}/download?formats=...`；`index.html` 增加下载格式弹窗 DOM，`frontend.js` 中 `startSongDownloadFlow` 等。

### 主要文件

- `app/main.py`：`streaming_download_song_file`、`zip_song_files_response`、`GET /songs/{id}/download`、`POST /admin/songs/batch-download`，及各类辅助函数；`GET /song-files/{id}/download` 使用统一命名。
- `app/schemas.py`：`BatchSongDownloadIn`、`SongOut.updated_at` 等。
- `requirements.txt`：增加 **tzdata**（保障 ZoneInfo 在精简镜像/Windows 下可用）。

## 3. 搜索、筛选与重置 UI

### 一键清空关键词

- 清空按钮在**输入框内部**右侧（绝对定位），非框外。
- **后台**：歌曲关键词 + 艺人/标签/语言/风格各管理页搜索框均支持。
- **前台**：曲库关键词同样支持。

### 重置按钮显隐

- **仅当**存在搜索关键词或任意筛选条件时显示「重置」；无关键词且筛选为空时隐藏（**不包含**仅改排序的情况）。
- **后台**：重置清空关键词、全部筛选项，排序恢复为「创建时间 / 降序」，并刷新列表。
- **前台**：重置清空关键词与三个下拉（格式/标签/语言），并 `loadSongs`。

### 布局与字号

- 搜索行 **`width: 100%`**；搜索区域 `flex` 拉长；前台三个筛选下拉**收窄**（约 88px 宽、`flex: 0 1`），搜索框 **`flex: 3`**、`min-width` 加大。
- 引入 **`--ui-search-font-size: 14px`**：搜索框、清空按钮、筛选标签与下拉、重置/展开筛选等同排按钮、列表行 `song-format-select` 等统一字号。

### 主要文件

- `app/static/styles.css`：变量、`search-field-wrap` / `search-clear-btn`、`admin-search-row`、前台 `front-filter-toolbar`、筛选网格等。
- `app/static/admin.html` / `admin.js`：DOM、`wireSearchFieldClear`、`updateAdminMusicResetVisibility`、`resetAdminSongListFilters` 等。
- `app/static/index.html` / `frontend.js`：`updateFrontResetVisibility`、`resetFrontSongListFilters` 等。
