## MODIFIED Requirements

### Requirement: 后台歌曲管理页列表表格列与顺序

后台壳内歌曲管理页主表格 SHALL 按下列顺序展示列（不含行首勾选列）：歌曲、原唱、作词、作曲、专辑、语言、**影视剧**、标签、格式、时长、发行日期、元数据、创建时间、更新时间、操作。

各列展示规则 SHALL 为：

| 列 | 数据来源 / 展示 |
|----|-----------------|
| 歌曲 | 歌曲标题；无副文案时长（时长独立列） |
| 原唱 | `lead_artist` 或等价主唱展示串 |
| 作词 | 词作者名字列表，以「、」或「 / 」连接 |
| 作曲 | 曲作者名字列表，以「、」或「 / 」连接 |
| 专辑 | 专辑名 |
| 语言 | 语言展示名 |
| 影视剧 | `film_tv` 文本；无值时显示「—」 |
| 标签 | 标签名列表 |
| 格式 | 代表性音频格式标签 |
| 时长 | `duration_ms` 格式化为 `mm:ss` |
| 发行日期 | `release_date` 原文或格式化展示 |
| 元数据 | 元数据完成度进度条与百分比 |
| 创建时间 | `created_at` 本地化展示 |
| 更新时间 | `updated_at` 本地化展示 |
| 操作 | 见「后台歌曲管理页列表操作按钮」 |

表格 MUST NOT 包含「年份」「封面」「状态」「歌词」列。

支持排序的列（若实现表头排序）SHALL 与上述字段对应，且排序请求参数与曲库列表 API 的 `sort_by` 一致；「影视剧」列排序参数 MUST 为 `film_tv`。

#### Scenario: 列顺序与必填字段展示

- **GIVEN** 歌曲管理页已加载且列表至少一条记录
- **WHEN** 用户查看表头
- **THEN** 表头从左至右（勾选列之后）依次为歌曲、原唱、作词、作曲、专辑、语言、影视剧、标签、格式、时长、发行日期、元数据、创建时间、更新时间、操作
- **AND** 不出现年份、封面、状态、歌词列

#### Scenario: 空字段占位

- **GIVEN** 某歌曲缺少作词或作曲关联，或 `film_tv` 为空
- **WHEN** 渲染该行
- **THEN** 对应单元格显示「—」或等价占位

#### Scenario: 影视剧列展示与排序

- **GIVEN** 某歌曲 API 响应 `film_tv` 为「琅琊榜」
- **WHEN** 该歌曲出现在后台列表中
- **THEN** 影视剧列单元格展示「琅琊榜」
- **WHEN** 用户点击影视剧列表头排序
- **THEN** 列表请求携带 `sort_by=film_tv` 及当前升降序参数

### Requirement: 前台壳音乐库歌曲列表列定义

前台壳音乐库歌曲表格 SHALL 包含以下列（从左至右）：**#**、**歌曲**、**原唱**、**作词**、**作曲**、**专辑**、**语言**、**影视剧**、**标签**、**格式**、**时长**、**发行日期**、**操作**。

序号列（`#`）SHALL 展示当前页内的行序号（随分页偏移递增，如第 2 页每页 20 条时首行显示 21）。歌曲列 SHALL 仅展示曲目标题及播放态指示（若当前正在播放）；MUST NOT 包含封面图、音符图标、`sk-thumb` 或任何等价歌曲图标/缩略图占位。

操作列 MUST 默认仅展示「更多」触发按钮（文案或图标为「⋯」或等价，含 `aria-label`）；试听、加入歌单、下载 MUST 置于该按钮展开的下拉菜单项中，且 MUST 保留既有权限与禁用逻辑（无网页可试听音频时试听/加入歌单为 disabled 并展示说明）。操作列 MUST NOT 在默认态并排展示多个独立图标按钮；MUST NOT 包含收藏按钮或等价占位控件。

列数据 SHALL 映射歌曲 API 响应字段：`lead_artist`、`lyricists`、`composers`、`album`、`language`、**`film_tv`**、`tags`、`formats`/`file_format`、`duration_ms`、`release_date`。

#### Scenario: 列表展示完整列

- **GIVEN** 用户打开音乐库且曲库有至少一首含完整元数据的歌曲
- **WHEN** 列表渲染完成
- **THEN** 表头依次为 #、歌曲、原唱、作词、作曲、专辑、语言、影视剧、标签、格式、时长、发行日期、操作
- **AND** 首列 `#` 展示当前页行序号

#### Scenario: 歌曲列无图标占位

- **GIVEN** 用户查看音乐库列表任意数据行
- **WHEN** 用户查看「歌曲」列单元格
- **THEN** 仅可见曲目标题文本及（若正在播放）播放态指示
- **AND** 不存在封面缩略图、音符图标或其它歌曲图标元素

#### Scenario: 元数据字段正确展示

- **GIVEN** 某歌曲 API 响应含 `lead_artist`、`lyricists`、`composers`、`film_tv`、`release_date`
- **WHEN** 该歌曲出现在音乐库列表中
- **THEN** 对应单元格展示正确文本（作词/作曲为多值时以可读形式合并展示；`film_tv` 为空时显示「—」）
- **AND** 发行日期以日期格式或占位符「—」展示

#### Scenario: 操作列默认仅展示更多按钮

- **GIVEN** 用户查看音乐库列表任意数据行
- **WHEN** 用户查看该行操作列且未展开菜单
- **THEN** 可见且仅可见一个「更多」触发按钮
- **AND** 不存在并排独立的试听、加入歌单、下载图标按钮

#### Scenario: 更多菜单提供前台既有操作

- **GIVEN** 用户查看音乐库列表中某首可网页试听的歌曲
- **WHEN** 用户点击该行「更多」并展开菜单
- **THEN** 菜单中存在试听、加入歌单、下载项
- **WHEN** 用户点击「试听」
- **THEN** 触发与既有行内试听按钮相同的播放行为
- **AND** 不存在收藏（♥）菜单项或按钮

## ADDED Requirements

### Requirement: 后台歌曲管理页编辑抽屉全高布局

后台壳内歌曲管理页右侧编辑面板（`#adminEditPanel` / `.admin-edit-panel`）在打开状态（`.is-open`）时 MUST 纵向占满 `.adm-workspace` 可用高度（100%）。面板 MUST 采用纵向 flex：`.drawer-head` 与 `.drawer-footer` 固定高度不收缩，`.drawer-body-scroll` 占据剩余空间并在内容溢出时内部纵向滚动。面板高度 MUST NOT 短于同工作区内主表格列可视区域高度。

#### Scenario: 打开抽屉时面板与表格同高

- **GIVEN** 用户打开某首歌曲的编辑抽屉
- **WHEN** 面板处于 `.is-open` 状态
- **THEN** 编辑面板从工作区顶部延伸至工作区底部（与左侧表格区同高）
- **AND** 表单正文在 `.drawer-body-scroll` 内滚动而非整页滚动

#### Scenario: 长表单可滚动

- **GIVEN** 编辑抽屉已打开且元数据与音频文件列表总高度超出面板可视区
- **WHEN** 用户在抽屉正文区域滚动
- **THEN** 仅 `.drawer-body-scroll` 区域滚动
- **AND** 抽屉头部标题与底部「取消」「保存」按钮保持可见且不随正文滚动

### Requirement: 后台歌曲管理页编辑抽屉无保存草稿

编辑抽屉底部操作区 MUST NOT 提供「保存草稿」按钮或等价的本地草稿保存入口。底部 MUST 仅保留「取消」与「保存」（或语义等价的关闭与提交元数据操作）。客户端 MUST NOT 因用户编辑元数据而向 `localStorage` 写入 `adm-draft-*` 草稿键。

#### Scenario: 抽屉底部无保存草稿

- **GIVEN** 用户打开某首歌曲的编辑抽屉
- **WHEN** 用户查看底部操作栏
- **THEN** 不存在「保存草稿」按钮
- **AND** 可见「取消」与「保存」按钮

#### Scenario: 编辑过程不写入本地草稿

- **GIVEN** 用户在编辑抽屉中修改歌曲名但未点击保存
- **WHEN** 用户点击「保存草稿」（若存在）或等价草稿触发控件
- **THEN** 该控件不存在，无法触发
- **AND** 关闭抽屉后再次打开仍显示服务端已保存数据（除非用户曾点击「保存」）
