## ADDED Requirements

### Requirement: 后台歌曲管理页表格冻结列

当歌曲管理页表格列总宽度超出列表滚动容器可视宽度时，用户横向滚动表格时**勾选**列与**歌曲**列 MUST 保持固定可见（sticky left），**操作**列 MUST 保持固定可见（sticky right）；表头与每一数据行同步冻结，中间列（原唱至更新时间）随横向滚动移动。

表格 MUST 使用 `border-collapse: separate`（或等价实现）以保证 sticky 列 z-index 在横向滚动时生效。冻结列单元格 MUST 使用不透明背景色覆盖其下方滚动列内容；横向滚动至任意位置时，滚动列的文字或控件 MUST NOT 与冻结列内容发生视觉重叠或「透出」。

操作列在用户横向滚动时 MUST 对表头与每一数据行均采用右侧冻结，使编辑、播放、下载、更多等主操作按钮始终贴在列表滚动容器右缘且可点击。操作列单元格 MUST 保持表格单元格显示类型；按钮组 flex 布局 SHALL 应用于单元格内层包裹元素（与「后台歌曲管理页列表操作按钮」一致）。

#### Scenario: 横向滚动时勾选与歌曲列固定

- **GIVEN** 用户处于歌曲管理页且表格需横向滚动
- **WHEN** 用户在 `.adm-table-scroll` 内向右滚动
- **THEN** 勾选列与歌曲列仍固定在容器左侧可见
- **AND** 原唱及后续中间列随滚动移出或进入视口

#### Scenario: 横向滚动时操作列固定

- **GIVEN** 用户处于歌曲管理页且表格需横向滚动
- **WHEN** 用户将表格横向滚动到任意位置
- **THEN** 操作列仍固定在容器右侧可见
- **AND** 用户能点击该行编辑、播放、下载、更多按钮而无需先滚回最右侧

#### Scenario: 冻结列 hover 与选中背景

- **GIVEN** 用户横向滚动后鼠标悬停某数据行，或该行处于 `is-active` 选中态
- **WHEN** 该行处于 hover 或选中态
- **THEN** 左侧勾选/歌曲与右侧操作冻结列单元格背景与该行视觉样式一致
- **AND** 不出现透底、错位或叠字

#### Scenario: 横向滚动时冻结列不透底

- **GIVEN** 歌曲管理表格中间列含较长文本且需横向滚动
- **WHEN** 用户横向滚动使某中间列文字经过左侧或右侧冻结列区域
- **THEN** 冻结列下方不可见该中间列文字或控件
- **AND** 冻结列内勾选框、歌曲名或操作按钮清晰可读、无叠字
