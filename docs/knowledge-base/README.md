# 知识库

`docs/knowledge-base/` 用于沉淀可复用经验：

- `best-practices/`：跨需求可复用的实现、测试、UI、存储和发布经验。
- `incidents/`：线上或本地重大故障复盘。
- `retrospectives/`：Sprint 复盘、Token 使用分析和行动项沉淀。
- `sprints/`：Sprint 复盘与行动项。

`/sprint-propose`、`/req-complete`、`/opsx-apply` 和 `/sprint-apply` 必须读取相关知识库条目，并说明适用或不适用原因。
